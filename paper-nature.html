atoma

Universal Molecular File Parser & Analyzer

5–13× faster than Biopython, RDKit, and OpenBabel

Dishant · github.com/Dishant707/molio

Molecular file parsing remains a bottleneck in structural biology. Existing Python-based tools (Biopython, RDKit, OpenBabel) parse files in tens to hundreds of milliseconds with multi-hundred-megabyte dependency chains. We present atoma, a Rust-based universal parser achieving 5–13× speed improvements in a 918 KB binary with zero dependencies. Atoma auto-detects PDB, mmCIF, SDF, and XYZ formats, and provides instant in-memory structural analysis: covalent bonds, steric clashes, Ramachandran φ/ψ outliers, secondary structure, and Shannon entropy. Available as CLI, 12 MB desktop GUI, and 126 KB WebAssembly web app requiring no installation.

Introduction

The central dogma—DNA → mRNA → protein → 3D structure—generates immense structural data. The PDB holds 200,000+ structures; AlphaFold has predicted 200+ million. Parsing these efficiently is critical for drug discovery and protein design. Yet the most-used tools are Python-based with 50–400 MB installs, parsing in tens to hundreds of milliseconds.

Atoma addresses this with three principles: zero-copy parsing using Rust's ownership model, content-based auto-detection (users never specify format), and single codebase, universal deployment—the identical Rust core compiles to CLI, GUI, and WebAssembly.
