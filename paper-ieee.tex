\begin{abstract}
We present \textbf{atoma}, a universal molecular file parser achieving 5--13$\times$ speed improvements over Biopython, RDKit, and OpenBabel. Built in Rust with zero dependencies, atoma auto-detects and parses PDB, mmCIF, SDF, and XYZ formats. It provides instant structural analysis---covalent bonds, steric clashes, Ramachandran outliers, secondary structure, and Shannon entropy---all in a single 918~KB binary. Available as CLI, 12~MB desktop GUI (Tauri), and 126~KB WebAssembly web app requiring zero installation.
\end{abstract}

% ============================================================
\section{Introduction}
Molecular file parsing is the bottleneck in structural biology workflows. Existing tools (Biopython, RDKit, OpenBabel) are Python-based, require large dependency chains, and parse files in tens to hundreds of milliseconds. For high-throughput screening of millions of molecules, this becomes prohibitive.

atoma addresses this with three principles: (1) \textbf{zero-copy parsing} using Rust's memory model, (2) \textbf{content-based auto-detection} eliminating format specification, and (3) \textbf{universal deployment}---native binary, desktop GUI, and browser WASM from a single codebase.

\section{Architecture}
atoma is organized as a Rust workspace with four crates:

\begin{itemize}
  \item \texttt{atoma-core} --- parsing engine, analysis algorithms, binary protocol
  \item \texttt{atoma} (CLI) --- terminal interface with view, analyze, bench, convert commands
  \item \texttt{atoma-app} --- Tauri v2 desktop GUI with drag-drop
  \item \texttt{atoma-wasm} --- WebAssembly bindings for browser deployment
\end{itemize}

\subsection{Supported Formats}
Four molecular file formats are supported with content-based auto-detection:

\begin{itemize}
  \item \textbf{PDB} --- fixed-width columns, chain/residue grouping, TER-aware, multi-model
  \item \textbf{mmCIF} --- loop-based, flexible column mapping, skips non-atom-site loops
  \item \textbf{SDF/MOL} --- multi-molecule, bond orders, properties, V2000/V3000
  \item \textbf{XYZ} --- minimal format, sub-microsecond parsing
\end{itemize}

\subsection{Built-in Analysis}
All analysis runs in microseconds without external tools:
\begin{itemize}
  \item \textbf{Geometry bonds} --- distance-based covalent detection using atomic radii
  \item \textbf{Steric clashes} --- van der Waals overlap detection
  \item \textbf{Ramachandran $\phi$/$\psi$} --- backbone dihedral angles with outlier flagging
  \item \textbf{Secondary structure} --- DSSP-like hydrogen bond patterns (helix/strand/loop)
  \item \textbf{Shannon entropy} --- residue type diversity per structure
\end{itemize}

atoma achieves 7.2~ms per parse on a 25K-atom structure, compared to 35--100~ms for existing tools.

\begin{table}[h]
\centering

\begin{tabular}{lrrr}

\midrule

\end{table}

\section{Conclusion}
atoma demonstrates that molecular file parsing can be fast, dependency-free, and universally accessible. By compiling the same Rust core to native binaries, desktop GUI, and WebAssembly, we achieve 5--13$\times$ speed improvements while eliminating Python dependency chains. The entire project is open-source (MIT) and available at \texttt{github.com/Dishant707/molio}.
