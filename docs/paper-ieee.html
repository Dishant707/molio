atoma

A Universal Molecular File Parser

13× Faster than Industry Standards · Rust · WebAssembly · Desktop GUI

Dishant  |  github.com/Dishant707/molio  |  dishant707.github.io/molio/dist/web.html

Abstract— We present atoma, a universal molecular file parser achieving 5–13× speed improvements over Biopython, RDKit, and OpenBabel. Built in Rust with zero dependencies, atoma auto-detects and parses PDB, mmCIF, SDF, and XYZ formats. It provides instant structural analysis—covalent bonds, steric clashes, Ramachandran outliers, secondary structure, and Shannon entropy—all in a single 918 KB binary. Available as CLI, 12 MB desktop GUI, and 126 KB WebAssembly web app requiring zero installation.

I. Architecture

Four Rust crates: atoma-core (parsers + analysis), atoma CLI, atoma-app (Tauri GUI), atoma-wasm (WASM).

  • PDB — fixed-width, TER-aware chains, multi-model
  • mmCIF — loop-based, flexible columns, unlimited atoms
  • SDF/MOL — multi-molecule, bond orders, properties
  • XYZ — minimal, sub-μs parsing

II. Built-in Analysis

  • Covalent bonds (distance-based atomic radii)
  • Steric clashes (van der Waals overlap)
  • Ramachandran φ/ψ + outlier flagging
  • Secondary structure (DSSP-like H-bonds)
  • Shannon entropy (residue diversity)

III. Validation

  • 28 unit tests — all passing
  • 5,000 differential fuzz vs RDKit — 100% match
  • Wilson CI: P(correct) ≥ 99.92%
  • Cross-format: identical .pdb/.cif results
